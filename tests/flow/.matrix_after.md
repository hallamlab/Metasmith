### Bag-shape goal (G2) — now CLOSED

Earlier the C5/C22/C23 strict assertions were left RED as a deferred
follow-up. They now PASS via per-by-key bagging in `_batch`:

- `Orchestrator.group()` classifies each non-by stream once at the top.
  If any stream is `DESCENDANT_OF_BY` or `SIBLING`, the group is in
  **per-key bag mode**. Otherwise (`PARENT_OF_BY` / `WILDCARD` only)
  the group stays in **consecutive collate mode** (legacy behavior,
  preserves C2 / C24).
- `_batch` in per-key mode keys each result by `common_index[by_name]`
  and runs `groupTuple(by: 0, size, remainder: true)`. Each by-item
  drives one bag of its matched descendant items, sized `batch_size`,
  with partial bags emitted at channel close.
- `_batch`'s legacy 2-arg signature `_batch(size, channel)` is
  preserved as a thin wrapper that routes to consecutive mode, so
  existing direct callers (`TestOrchestratorBatch` and any external
  workflow code) continue to work unchanged.
